Smartech Typing Tutor - how to add TEST TYPES + their exercises (paste into your GitHub exercise file)
Anything above the first ### line is ignored. Keep your existing exercises exactly as they are.

=====================  3) ONE TEST WITH ENGLISH + PUNJABI  =====================
List both languages in "language:". The Test Centre card and the exercise page then show
English and Punjabi as two separate blocks (each with its own time, pass rule and exercise
numbering starting at 1). Optional own rule per language: <language>-wpm / -chars / -accuracy /
-minutes. Anything not overridden is taken from the main fields.

=====================  4) PHHC / WORD-BASED TEST (own result engine)  =====================
A test with  "engine: words"  is NOT calculated on 5 keystrokes = 1 word. It counts the words
really typed:
    Typed words  = all words typed
    Mistakes     = wrong + extra + skipped words + merged/split words ("goodmorning", "to day")
    Net words    = Typed words - Mistakes
    Result speed = Net words / minutes            e.g. (typed - mistakes) / 10
    Pass         = Net words >= required words    e.g. 300 words in 10 minutes (= 30 WPM)
A test whose ID starts with PHHC uses this engine automatically (add "engine: chars" to opt out).
No accuracy rule is applied unless you write "accuracy:".

### TEST PHHC
name: Punjab & Haryana High Court
language: English
mode: paragraph
minutes: 10
words: 300
code: PHHC
description: Result speed = (typed words - mistakes) / 10. Pass: 300 words in 10 minutes.

### English @PHHC Passage 1
---
English passage ...
---

Optional fields for a word-based test:
  words            minimum NET words in the test time (default 300); or  wpm: 30  (= 300 words in 10 min)
  basis            net (default) = typed - mistakes must reach the target; gross = typed words only
  space-mistakes   yes = every extra spacebar press is also a mistake (default no: only shown with a blue mark)
  case-sensitive   yes = "court" for "Court" is a wrong word (default no, same as the other tests)
  accuracy         optional extra rule: net words / typed words (default none)
  <language>-words own words target per language, e.g. punjabi-words: 250

=====================  FIELD GUIDE  =====================
name         Title on the Test Centre card (default: the ID)
language     English / Punjabi / Hindi, or several separated by a comma ("English, Punjabi").
             Each exercise keeps its own language; a multi-language test shows one block per language.
english-wpm  Optional per-language rule: <language>-wpm, -chars, -accuracy, -minutes
             (e.g. punjabi-wpm: 30). Not given = the main value is used.
engine       chars (default) = characters, 5 chars = 1 word | words = PHHC: real typed words (section 4)
mode         paragraph = long passage page, chunk = chunk page (default paragraph)
minutes      Test time, fixed for this test (default 10)
wpm          Minimum speed in words/min (1 word = 5 characters)      } use ONE of
chars        Minimum characters instead of wpm (e.g. 2000)           } wpm or chars
accuracy     Minimum accuracy % (default 90)
basis        gross (default) or net - which character count must reach the speed target
code         Access-code TYPE in the Google Sheet. FREE = no code. If left out, the
             test ID itself is the code type (locked by default).
description  Optional line on the card
note         Optional line printed under the result
active       no = hide the test without deleting it
subtitle     Optional small label under the name on the home-screen card (default "Typing Test")
color        Optional card colour on the home screen: blue, amber, green, rose, violet, teal, sky
             (default: the cards rotate through the colours)
icon         Optional card icon: scales, cap, dome or badge (default: chosen from the name -
             court -> scales, university/college -> cap, SSC / RRB / Bank -> badge, else dome)

Rules: a test ID may use letters, digits, - and _ (no spaces). Pass = speed target reached
AND accuracy reached. Tests with the same "code:" share one activation.
